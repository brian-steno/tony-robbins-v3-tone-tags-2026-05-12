How To Review

Suggested workflow

  1. Open the hosted links in the scorecard below.
  2. Use the same 2–3 prompts in each lane before judging.
  3. Score subjective quality first, then use latency/cost as tie-breakers.
  4. Use the static clips only as supporting evidence, not the only signal.

Review rubric

  • Likeness to Tony
  • Warmth and authority
  • Clarity and pronunciation
  • Pacing, pauses, and breath feel
  • Energy and emotional control
  • Realtime feel / responsiveness
